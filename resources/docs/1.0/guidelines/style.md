## Technologies

The stylesheets in this project will be written in [SCSS](https://sass-lang.com/).
Using the [BEM](https://en.bem.info/) methodology.
Meaning they should be modular and reusable.

## Aesthetics

The look and feel should aim for a simple, low-stimuli, Windows95-esque look and feel.

Use dithered gradients in the background.
Borders are clear and direct.
Pseudo 3d effects on borders and buttons with darker and lighter shades at the edges.

Small 6 - 15fps animation where something dynamic is preferred.

## Color Palette

Use a color palette that is consistent with the Windows95 aesthetic.
Inspired by that, i created my Color Palette. Adding orange as that is my favorite color with black.
![Color Palette](https://www.game-object.de/media/afda5a00-5cd2-47c7-9afb-f25fa0fcda5a/color-palette.png)

- Turquoise #6cdad9 : Used primarily for interesting backgrounds. 
- Gray #6c6c6c : Used for borders and functional backgrounds.
- Blue #26306a : Alternative Text color, to highlight. 
- Orange #d48c17 : Alternative background, to highlight.
- Black #111111 : Text color and clear cut borders.

## Typography
