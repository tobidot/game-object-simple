# Website History

This is a documentation of all my attempts to build a personal website over the years.

---

### [My Internet](./my-internet)
- **Timestamp:** ~July 2015
- **Thought:** Back to basics. A collection of raw HTML and CSS pages to practice the fundamentals of web development.
- **Content:** A personal knowledge base with sections for Photos, Life, Philosophy, Programming, and general knowledge.

### [Tobias at gepp-im-web.de](./tobias-at-gepp-im-web-de)
- **Timestamp:** April 2018
- **Thought:** A simple landing page with a login and some basic tools like a "Planer".
- **Content:** Basic HTML/PHP site with an impressum and a login-protected area.

### [PP Theme (ProjektPrestation)](./pp-theme)
- **Timestamp:** July 2018
- **Thought:** My first serious attempt at creating a custom WordPress theme using the Underscores starter theme as a base.
- **Content:** A clean, minimal WordPress theme structure.

### [PP Wordpress](./pp-wordpress)
- **Timestamp:** 2018 - 2019
- **Thought:** The full WordPress installation for testing and developing the PP Theme.
- **Content:** A complete WordPress site including plugins like Advanced Custom Fields and various test content.

### [Tobias Gepp im Web](./tobias-gepp-im-web-de)
- **Timestamp:** 2019 - 2021
- **Thought:** Another WordPress-based iteration, likely more focused on personal branding and professional presence.
- **Content:** WordPress content and configuration for the `gepp-im-web.de` domain.

### [Game-Object.com](./game-object.com)
- **Timestamp:** April 2021
- **Thought:** Moving towards modern frameworks with Laravel. A more structured and scalable approach to building my site.
- **Content:** A Laravel-based website with Laradock support for development.

### [The Final Project Order Server](./the-final-project-order-server)
- **Timestamp:** May 2022
- **Thought:** A tool designed to help organize and interpret project structures via JSON.
- **Content:** A backend service for managing project metadata and organization.

### [My Home (Current)](./my-home)
- **Timestamp:** January 2023 - Present
- **Thought:** The latest iteration, built with Laravel, Nova, and LaRecipe for comprehensive documentation and project management.
- **Content:** CMS for pages and projects, documentation hub, and a platform for live demos.
